## 3. Разбор полетов (Инсайты)

### Провал на генерации фичи (Feature)
Локальные модели класса 7-8B **не справляются с full-stack задачами** (UI + State + Persistence) с одного промпта.
- **Llama 3.1 8B** сломалась на синтаксисе тулзов: вместо готового кода она попыталась сгенерировать JSON-команду редактирования файла, сломала синтаксис и выдала некомпилируемый кусок.
- **Qwen 2.5 Coder 7B** повел себя иначе: он попытался переписать весь проект (начиная с `build.gradle.kts` и `AppModule`), но забыл добавить зависимости. Добравшись до нужного интерфейса `ScenarioRepository`, он написал устаревший блокирующий Java-код (`FileWriter`, `JSONArray`, полностью проигнорировав правило о Coroutines), а саму функцию `loadFromJson` просто бросил с комментарием `// Add the implementation`. Это типичная проблема ограниченного "внимания" (context window) у малых моделей.

### Режим Research (Анализ кодовой базы)
- **Llama** увидела "Kotlin + UI" и решила, что это Android-разработка (выдумав папки `androidTest`). Слово "cases" из контекста QA-сценариев она интерпретировала как "Test Cases" (юнит-тесты).
- **Qwen** показал себя гораздо лучше: он правильно идентифицировал слои (Domain, Feature) и понял, что создание кейса завязано на метод `saveToJson()`, который он же сам (хоть и криво) пытался сгенерировать шагом ранее.

### Скорость
Вопреки моим ожиданиям, на M4 с 16 ГБ RAM локальные модели генерируют токены **очень быстро**, задержек в интерфейсе IDE не ощущается вообще.

## 4. Рекомендация: Для чего хватает локальной модели?

**Локальная связка (Qwen 7B / Llama 8B) достаточна для:**
- Автокомплита "на лету" (Tab Autocomplete) в рамках одного файла.
- Написания javadoc или простых DTO/мапперов.
- Объяснения небольших кусков выделенного кода.
- Работы в офлайне (в самолете/поезде).

**Облако незаменимо для:**
- **Агентного режима:** автоматический запуск тестов, использование Bash/MCP тулзов.
- **Full-stack фичей:** когда нужно связать UI-компонент, ViewModel и слой данных.
- **Точного следования архитектурным правилам:** облачные модели не "забывают" системный промпт (Coroutines, UDF) под весом большого контекста файлов.
